# 接口文档

> 完整 API 列表与请求/响应示例。所有接口的 OpenAPI 描述也可通过启动后端后访问 `http://localhost:8000/docs` 在线查看。

## 1. 教材管理（textbooks）

### 1.1 上传教材

```http
POST /api/textbooks/upload
Content-Type: multipart/form-data
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | ✓ | 支持 .pdf / .md / .txt / .docx |

**响应 200**
```json
{
  "textbook_id": "tb_abc123",
  "filename": "生理学.pdf",
  "format": "pdf",
  "size": 8523174,
  "status": "uploaded"
}
```

### 1.2 解析教材

```http
POST /api/textbooks/{textbook_id}/parse
```

异步触发解析任务，返回任务句柄。

**响应 200**
```json
{
  "textbook_id": "tb_abc123",
  "status": "parsing",
  "message": "解析任务已启动"
}
```

### 1.3 教材列表

```http
GET /api/textbooks/
```

**响应 200**
```json
{
  "textbooks": [
    {
      "textbook_id": "tb_abc123",
      "title": "生理学",
      "format": "pdf",
      "total_pages": 520,
      "total_chars": 385000,
      "status": "completed",
      "chapter_count": 12
    }
  ]
}
```

### 1.4 教材详情

```http
GET /api/textbooks/{textbook_id}
```

**响应 200**
```json
{
  "textbook_id": "tb_abc123",
  "title": "生理学",
  "chapters": [
    {
      "chapter_id": "ch_01",
      "title": "第一章 绪论",
      "page_start": 1,
      "page_end": 15,
      "char_count": 8500
    }
  ]
}
```

### 1.5 删除教材

```http
DELETE /api/textbooks/{textbook_id}
```

**响应 200**
```json
{ "deleted": true, "textbook_id": "tb_abc123" }
```

## 2. 知识图谱（graph）

### 2.1 提取知识图谱

```http
POST /api/graph/extract/{textbook_id}
```

**响应 200**
```json
{
  "task_id": "task_xyz",
  "stream_url": "/api/graph/extract/tb_abc123/progress"
}
```

### 2.2 提取进度（SSE）

```http
GET /api/graph/extract/{textbook_id}/progress
Accept: text/event-stream
```

**事件流**
```
event: progress
data: {"current_chapter": 3, "total": 12, "nodes_extracted": 18}

event: progress
data: {"current_chapter": 12, "total": 12, "nodes_extracted": 72}

event: done
data: {"total_nodes": 72, "total_edges": 58}
```

### 2.3 获取节点

```http
GET /api/graph/nodes?textbook_id=tb_abc123
```

| 参数 | 说明 |
|------|------|
| textbook_id | 可选。不传则返回所有教材的节点 |

**响应 200**
```json
{
  "nodes": [
    {
      "id": "node_001",
      "name": "动作电位",
      "definition": "细胞受到刺激后，膜电位发生的一次快速而可逆的倒转...",
      "category": "核心概念",
      "chapter": "第二章 细胞的基本功能",
      "page": 35,
      "textbook_id": "tb_abc123"
    }
  ]
}
```

### 2.4 获取关系

```http
GET /api/graph/edges?textbook_id=tb_abc123
```

**响应 200**
```json
{
  "edges": [
    {
      "source": "node_001",
      "target": "node_002",
      "relation_type": "prerequisite",
      "description": "理解动作电位需要先掌握静息电位的概念"
    }
  ]
}
```

### 2.5 跨教材整合

```http
POST /api/graph/merge
Content-Type: application/json

{
  "textbook_ids": ["tb_abc123", "tb_def456", "tb_ghi789"],
  "similarity_threshold": 0.85
}
```

**响应 200**
```json
{
  "decisions": [
    {
      "decision_id": "merge_001",
      "action": "merge",
      "affected_nodes": ["tb_abc123_n15", "tb_def456_n32"],
      "result_node": "merged_001",
      "reason": "三本教材均覆盖炎症概念，保留病理学版本",
      "confidence": 0.92
    }
  ],
  "stats": {
    "original_nodes": 192,
    "merged_nodes": 138,
    "compression_ratio": 0.274,
    "merge_count": 38,
    "keep_count": 12,
    "remove_count": 4
  }
}
```

## 3. RAG 问答（rag）

```http
POST /api/rag/index
Content-Type: application/json

{ "textbook_ids": ["tb_abc123", "tb_def456"] }
```

**响应 200**
```json
{
  "indexed_textbooks": 2,
  "total_chunks": 487,
  "chunk_size": 600,
  "overlap": 100,
  "embedding_model": "Qwen/Qwen3-Embedding-8B"

```

POST /api/rag/query

{

## 4. 多轮对话（chat）

### 4.1 发送消息

```http
POST /api/chat/message
Content-Type: application/json

{
  "session_id": "sess_001",
  "message": "为什么把'炎症'和'炎症反应'合并了？"
}
```

**响应 200**
```json
{
  "session_id": "sess_001",
  "reply": "因为这两个节点的语义相似度为 0.91，且 LLM 判定为同一概念。保留了《病理学》的版本，因其定义最系统完整。",
  "intent": "explain_decision",
  "graph_updated": false
}
```

意图修改示例：

```json
{
  "session_id": "sess_001",
  "message": "把'抗原'和'免疫原'分开"
}
```

```json
{
  "session_id": "sess_001",
  "reply": "已将'抗原'和'免疫原'拆分为独立节点，图谱已更新。",
  "intent": "split_nodes",
  "graph_updated": true,
  "modified_nodes": ["merged_018"]
}
```

### 4.2 对话历史

```http
GET /api/chat/history?session_id=sess_001
```

**响应 200**
```json
{
  "session_id": "sess_001",
  "messages": [
    { "role": "user", "content": "为什么...", "timestamp": "..." },
    { "role": "assistant", "content": "因为...", "timestamp": "..." }
  ]
}
```

## 6. 错误响应

所有接口在异常时返回统一格式：

```json
{
  "error": {
    "code": "TEXTBOOK_NOT_FOUND",
    "message": "未找到指定教材",
    "details": { "textbook_id": "tb_xxx" }
  }
}
```

| HTTP 状态码 | 含义 |
|------------|------|
| 400 | 参数错误（如不支持的文件格式） |
| 404 | 资源不存在 |
| 413 | 文件超出大小限制（500MB） |
| 422 | 业务校验失败（如压缩比无法满足） |
| 500 | 服务器内部错误 |
| 502 | LLM/Embedding API 调用失败 |
