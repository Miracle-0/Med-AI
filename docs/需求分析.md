# 需求分析

## 1. 问题分解

### 1.1 知识点粒度定义
- 知识点粒度：以"概念"为基本单位，包括核心概念、定理、方法、现象
- 粒度标准：能够独立定义、可与其他知识点建立关系

### 1.2 重复判定标准
- 语义相似度阈值：0.85（基于向量余弦相似度）
- LLM判断：当相似度在0.7-0.85之间时，使用LLM辅助判断

### 1.3 教学连贯性保障
- 保留知识点之间的依赖关系
- 确保核心概念不被删除
- 压缩比控制在30%以内

### 1.4 压缩比计算方式
- 压缩比 = 1 - (整合后知识点数 / 原始知识点数)
- 目标：压缩比 ≤ 30%

### 1.5 RAG分块策略
- 分块大小：500-800字
- 重叠：50-100字
- 理由：足够包含一个完整知识点，又不会太长影响检索精度

## 2. 子问题分析

### 2.1 文件解析
- 支持格式：PDF、Markdown、TXT
- 解析内容：章节结构、正文内容
- 输出：结构化JSON数据

### 2.2 知识提取
- 提取内容：概念名称、定义、分类
- 关系类型：前置依赖、并列、包含、应用
- 方法：LLM提取 + 结构化输出

### 2.3 知识整合
- 对齐方法：向量相似度 + LLM判断
- 决策类型：合并、保留、删除
- 验证：压缩比检查

### 2.4 RAG问答
- 检索策略：向量检索（FAISS）
- 生成策略：上下文注入 + LLM生成
- 引用格式：[教材名, 章节, 页码]
