# 系统设计

## 1. 架构设计

### 1.1 整体架构
采用LangGraph状态机 + FastAPI混合架构。

- 前端：React + ECharts
- 后端：FastAPI
- AI引擎：LangGraph
- 数据层：SQLite + FAISS

### 1.2 数据流
1. 用户上传教材 → 文件解析 → 存储到SQLite
2. 触发知识提取 → LLM提取知识点 → 存储到数据库
3. 触发整合 → 向量相似度计算 → LLM判断 → 生成决策
4. 用户提问 → 向量检索 → LLM生成回答 → 返回带引用的答案

## 2. 技术选型

| 组件 | 技术 | 选择理由 |
|------|------|----------|
| 前端框架 | React 18 | 生态成熟，组件库丰富 |
| 可视化库 | ECharts 5 | 中文文档好，简单易用 |
| 后端框架 | FastAPI | 异步支持好，性能优秀 |
| AI框架 | LangGraph | 状态机编排，流程清晰 |
| 向量库 | FAISS | 轻量级，性能好 |
| 数据库 | SQLite | 简单易用，无需额外部署 |
| LLM | OpenAI API | 效果好，接口标准 |

## 3. API接口

### 3.1 教材管理
- POST /api/textbooks/upload - 上传教材
- GET /api/textbooks - 获取列表
- GET /api/textbooks/{id} - 获取详情
- DELETE /api/textbooks/{id} - 删除教材

### 3.2 知识图谱
- POST /api/graph/extract/{id} - 提取知识点
- GET /api/graph/nodes - 获取节点
- GET /api/graph/edges - 获取边
- POST /api/graph/merge - 执行整合

### 3.3 RAG问答
- POST /api/rag/index - 建立索引
- POST /api/rag/query - 提问
- GET /api/rag/status - 索引状态

### 3.4 对话
- POST /api/chat/message - 发送消息
- GET /api/chat/history - 对话历史
