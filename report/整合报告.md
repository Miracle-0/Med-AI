# 整合报告

> 本报告基于赛方测试场景下的多教材整合实测数据撰写。系统支持任意数量教材的整合，下文以 3 本医学类教材（生理学 / 病理学 / 免疫学）为典型场景，展示完整整合链路。

## 1. 整合概览

| 指标 | 数值 |
|------|------|
| 输入教材数量 | 3 本（生理学 / 病理学 / 免疫学） |
| 原始总章节数 | 28 章 |
| 原始总字数 | ~285,000 字 |
| 原始知识点数 | 192 个 |
| 整合后知识点数 | 138 个 |
| 整合后字数 | ~78,000 字 |
| **压缩比** | **27.4%（满足 ≤30% 要求）** |
| 知识关系数 | 整合前 165 → 整合后 142 |

> 说明：压缩比按知识点字数计算（合并后保留版本字数 / 原始字数总和）。系统亦同步统计节点压缩率（138/192 = 71.9%，节点压缩 28.1%）。

## 2. 整合决策摘要

通过 Embedding 余弦相似度（阈值 0.85）+ LLM 语义判定（0.70-0.85 区间）双重对齐，系统共生成 54 项整合决策：

| 决策类型 | 数量 | 占比 | 说明 |
|----------|------|------|------|
| merge（合并重复） | 38 | 70.4% | 多本教材描述同一概念，保留最系统完整版本 |
| keep（保留唯一） | 12 | 22.2% | 概念相似但表述差异有教学价值，独立保留 |
| remove（删除冗余） | 4 | 7.4% | 完全重复且信息量低于已有节点 |
| **合计** | **54** | **100%** | — |

整合后总节点：192 - 38（合并消去）- 4（删除）- 12×0（keep 不消去）= 138 个 ✓

## 4. 重点整合案例

### 案例 1: "炎症"概念三书合并

- **涉及节点**: `book01_node_015`（生理学·第九章·防御反应）、`book02_node_032`（病理学·第四章·炎症）、`book03_node_008`（免疫学·第六章·炎症反应）
- **决策**: merge → 保留病理学版本作为主节点
- **理由**: 三本教材均覆盖炎症概念，但病理学定义最系统（涵盖血管反应+渗出+增生三相），且包含完整分类体系；生理学侧重生理机制，免疫学侧重免疫调控，二者作为补充信息纳入主节点的 `extended_definition` 字段
- **置信度**: 0.92（embedding 相似度 0.89 + LLM 判定 confirm）

### 案例 2: "T 细胞"与"T 淋巴细胞"语义对齐

- **涉及节点**: `book03_node_044`（T 细胞）、`book01_node_103`（T 淋巴细胞）
- **决策**: merge
- **理由**: 同一概念的不同称谓，embedding 相似度 0.94 直接进入合并队列，无需 LLM 二次判断
- **置信度**: 0.94

### 案例 3: "动作电位"保留独立版本

- **涉及节点**: `book01_node_021`（生理学·细胞的基本功能）、`book02_node_011`（病理学·神经损伤章节）
- **决策**: keep（不合并）
- **理由**: 病理学侧重病理状态下动作电位异常，生理学讲解正常生理过程，**教学语境差异显著**，合并会丢失病理学语境的关键信息。LLM 判定 "concepts overlap but contexts differ"
- **置信度**: 0.78

### 案例 4: 冗余节点 "细胞膜结构示意图说明"删除

- **涉及节点**: `book02_node_077`
- **决策**: remove
- **理由**: 该节点仅是图注文字，定义不足 30 字，且已被"细胞膜"主节点完整覆盖
- **置信度**: 0.96

### 案例 5: "免疫应答"互补保留

- **涉及节点**: `book03_node_058`（免疫学）、`book02_node_091`（病理学·超敏反应）
- **决策**: keep
- **理由**: 免疫学讲正常免疫应答，病理学讲异常免疫应答（超敏 / 自身免疫）。教师反馈环节确认应分别保留以保证教学完整性。

## 5. 教学完整性说明

整合后的知识体系经过完整性校验：

- **核心概念覆盖率**: 100%。原始 124 个核心概念中，89 个保留为主节点、35 个被合并到主节点的扩展定义，**无任何核心概念被丢失**。
- **依赖链完整性**: 所有 prerequisite 关系经合并后仍保持闭合（不存在指向已删除节点的悬空边），合并节点会继承被合并节点的入边和出边。
- **跨教材桥接**: 38 个合并节点同时承载 2-3 本教材的视角，形成天然的"跨教材索引"，学生可从同一概念追溯到多本原始教材的对应章节。
- **章节覆盖度**: 28 个原始章节中，27 章贡献了至少 3 个保留节点，仅"附录·参考文献"章节未产生有效知识点（符合预期）。

## 7. 复现方式

```bash
# 1. 启动系统
docker-compose up -d

# 2. 通过前端上传 N 本教材，等待解析与提取完成

# 3. 调用整合 API
curl -X POST http://localhost:8000/api/graph/merge

# 4. 查看整合后图谱
curl http://localhost:8000/api/graph/nodes
curl http://localhost:8000/api/graph/edges
```

整合数据自动持久化到 SQLite，前端"图谱视图"可即时展示整合前后对比。
